## <mark>💬 Each group shares their costings</mark>

## Report-Back Structure

- Group 1: "We costed batch ETL: AWS £X, Azure £Y, GCP £Z"
- Group 2: "Streaming was more expensive because 24/7... AWS £X, Azure £Y, GCP £Z"
- Group 3: "Analytics has huge storage so... AWS £X, Azure £Y, GCP £Z"
- Group 4: "We also costed batch ETL: AWS £X, Azure £Y, GCP £Z"

## Then discuss:

- Groups 1 and 4 costed the same requirements - why do their numbers differ? (VM series, storage tier, region, database options)
- Which provider was consistently cheapest?
- What makes costs vary? (compute hours, storage volumes, data transfer)
- How does this inform your planning decisions?
