## Mermaid ERD Demo

- Do not assume learners have seen Mermaid ERDs before - treat this as a first introduction, not a refresher
- Open `notes.qaalabs.com` and type live - do not prep a page in advance
- Five steps: relationship line only, cardinality symbols, add attributes, add PK/FK, a many-to-many example
- Keep the example generic (Author/Book, Student/Course) - do NOT use the healthcare entities, Activities 1 to 3 should not be spoiled
- Groups will draw their conceptual model this way in Activity 2, in their group HedgeDoc page
- Mermaid also renders in GitHub `.md` files natively - worth a one-liner before handing over
- Full demo script in `day3/storage/mermaid-erd.md`
