## Lab 1b: Git in VS Code

- Bridges Lab 1 (Terminal + Notepad) to Day 3, which is done entirely in VS Code
- Uses the `my-git-project` folder from Lab 1 - if a learner lost it, they can redo Lab 1 Steps 2-4 quickly
- Key point: VS Code shows the same Git state they just saw in Terminal - the **M** marker and Source Control count are a live `git status`
- Show the side-by-side diff in the Source Control panel - most learners have not seen a diff before
- Git commands stay in the terminal, matching Day 3 - the Source Control panel's commit button is optional, mention it but don't teach it
- If `code .` does nothing, check they are in plain Terminal (not Git Bash) and in the project folder
