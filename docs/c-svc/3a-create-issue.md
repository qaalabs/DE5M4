# Activity 3: Creating an Issue on GitHub

**Objective**: Learn how to raise and describe an issue in a GitHub repository, such as a bug report, feature request, or documentation improvement.

## Instructions

### 1. Navigate to the team repository

- Open your web browser and go to: [https://github.com/](https://github.com/)
- Log in to GitHub if you're not already logged in.
- Go to the repository where you want to create the issue:
    - [https://github.com/ingwanelabs/intro-to-github](https://github.com/ingwanelabs/intro-to-github)

### 2. Go to the Issues Tab

- At the top of the repository page, click the **"Issues"** tab (near "Code", "Pull requests", etc.).

### 3. Click "New issue"

- On the Issues page, click the green **“New issue”** button on the right-hand side.

### 4. Choose an Issue Template (if available)

- If the repository has templates (e.g., Bug report, Feature request), select the appropriate one.
- If not, proceed with the default blank issue.

### 5. Enter the Issue Title and Description

- **Title**: Provide a short, clear title (e.g., *"Login form does not handle empty fields properly"*).
- **Description**: Use the comment box to describe the issue in detail.

  * Include steps to reproduce the problem (if it's a bug)
  * Explain why the feature would be useful (if it's a request)
  * Add screenshots or code examples if relevant

### 6. (Optional) Add Labels, Assignees, or Milestones

- If you have permission, you can:

  * Add **labels** (like `bug`, `enhancement`, `documentation`)
  * Assign the issue to yourself or a teammate
  * Add to a **milestone** or project board

### 7. Submit the Issue

- Click the green **“Submit new issue”** button at the bottom.

### Reflection / Discussion Questions

- Why is it important to write clear and descriptive issues?
- How can labels help a team manage issues?
- What's the difference between an issue and a pull request?
