# Possible User Stories for the QARestaurant Activity

Here are example user stories organised by the epics we identified, based on the restaurant website requirements:

## Epic: Restaurant Brand Identity

**Logo and Branding:**

- As a **first-time visitor**, I want to see the restaurant logo prominently displayed, so that I can easily identify and remember the restaurant brand.
- As a **customer browsing multiple tabs**, I want to see the restaurant logo in the browser tab, so that I can quickly find the restaurant's website among my open tabs.
- As a **returning customer**, I want to see consistent branding throughout the website, so that I feel confident I'm on the right restaurant's site.

## Epic: Customer Website Navigation

**Navigation and User Experience:**

- As a **website visitor**, I want to easily switch between different pages, so that I can find the information I need without getting lost.
- As a **potential customer**, I want a clear navigation menu, so that I can quickly access the menu, reservations, and contact information.
- As a **mobile user**, I want the website to work well on my phone, so that I can browse the restaurant information while on the go.

## Epic: Restaurant Information Display

**Menu Display:**

- As a **hungry customer**, I want to view menu items with titles, descriptions, and prices, so that I can decide what to order and budget for my meal.
- As a **person with dietary restrictions**, I want to see detailed descriptions of each menu item, so that I can make informed choices about what's safe for me to eat.

**About and Location:**

- As a **curious diner**, I want to learn about veganism on the About Us page, so that I can understand the restaurant's philosophy and feel more comfortable dining there.
- As a **potential customer**, I want to see pictures of the restaurant's food, so that I can get excited about dining there and know what to expect.
- As a **person unfamiliar with the area**, I want to clearly see the restaurant's address, so that I can easily find the location using GPS or maps.
- As a **foodie**, I want to read about the head chefs, so that I can appreciate the expertise behind the menu and feel confident about the food quality.

## Epic: Online Ordering System

**Ordering Functionality:**

- As a **busy customer**, I want to order food online, so that I can save time and have my meal ready when I arrive or delivered to me.
- As a **customer planning a meal**, I want to add multiple items to my order, so that I can get everything I want in one transaction.
- As a **customer with specific preferences**, I want to customise my order with special instructions, so that the restaurant can prepare my food exactly how I like it.

## Epic: Reservation Management System

**Customer Reservations:**

- As a **customer planning dinner**, I want to see available reservation times, so that I can book a table that fits my schedule.
- As a **customer making plans**, I want to book a table online, so that I can secure my reservation without having to call during business hours.
- As a **customer with changing plans**, I want to modify my reservation online, so that I can adjust my booking without calling the restaurant.

**Staff Reservation Management:**

- As a **restaurant staff member**, I want to update reservations when customers call, so that I can accommodate their changes and keep our booking system accurate.
- As a **restaurant manager**, I want to delete canceled reservations, so that those tables become available for other customers.
- As a **host/hostess**, I want to see all reservations for the day, so that I can properly prepare for incoming guests and manage seating efficiently.

## Epic: Customer Communication

**Social Media and Contact:**

- As a **social media user**, I want to see links to the restaurant's social media accounts, so that I can follow them for updates, special offers, and food photos.
- As a **customer with questions**, I want access to contact information, so that I can reach out about allergies, special events, or other inquiries.
- As a **customer who enjoyed my meal**, I want to share the restaurant on social media, so that I can recommend it to my friends and followers.

## Additional Advanced User Stories

**For more experienced groups, you might include:**

- As a **restaurant owner**, I want to track which menu items are most popular online, so that I can optimise my kitchen preparation and ingredient ordering.
- As a **customer loyalty program member**, I want to see my reward points when I log in, so that I can track my progress toward free meals.
- As a **restaurant staff member**, I want to receive notifications about new online orders, so that I can start preparing food promptly.
