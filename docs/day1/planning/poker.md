# Planning Poker

| Value  | Meaning / Use                                        |
| -------| ---------------------------------------------------- |
| `0`    | “No effort” — already done, or negligible            |
| `0.5`  | Trivial — tiny fix or tweak                          |
| `1-13` | Core Fibonacci — realistic, small-to-medium stories  |
| `20`   | Larger — possibly needs breaking down                |
| `40`   | Much larger — rarely used, red flag                  |
| `100`  | Massive — usually too big, should be split           |
|        |                                                      |
| `Hand` | **Hand-up** - signals that you need more information |
| `?`    | **Not Sure** - signals uncertainty                   |
| ☕     | **Break** - signals you will not be voting           |
