# Planning Poker Estimation Activity

## Items to Estimate for the Restaurant Website

Here are user stories of varying complexity that work well for Planning Poker practice:

### Simple Stories (1-2 story points)

- As a **customer**, I want to see the restaurant's phone number on the contact page, so that I can call with questions.
- As a **website visitor**, I want to see social media icons in the footer, so that I can follow the restaurant on different platforms.
- As a **customer**, I want to see the restaurant's address clearly displayed, so that I can find the location.

### Medium Stories (3-5 story points)

- As a **customer**, I want to view the full menu with prices, so that I can decide what to order and budget for my meal.
- As a **potential diner**, I want to read about the restaurant's vegan philosophy on the About Us page, so that I understand their approach to food.
- As a **customer**, I want to see available reservation times for a specific date, so that I can book a table that fits my schedule.

### Complex Stories (8-13 story points)

- As a **customer**, I want to place an online order with multiple items, so that I can have my food ready for pickup or delivery.
- As a **restaurant staff member**, I want to manage reservations (view, update, delete), so that I can accommodate customer changes and maintain accurate bookings.
- As a **customer**, I want to create an account and save my preferences, so that future ordering is faster and more convenient.

### Very Complex Stories (13-21 story points)

- As a **restaurant owner**, I want a complete reservation management system with calendar view, table assignments, and customer history, so that I can optimise seating and provide better service.
- As a **customer**, I want a full online ordering system with payment processing, order tracking, and delivery scheduling, so that I can have a complete digital dining experience.

---
## Learning Objectives

**This activity helps learners:**

- Practice relative estimation rather than absolute time estimates
- Experience the collaborative discussion that improves estimation accuracy
- Understand how team consensus emerges through Planning Poker
- See how breaking down complex stories leads to better estimates
- Learn to identify when more information is needed before estimating

## Connection to Data Engineering

In your data engineering work, you'll estimate stories like:

- 'As a data analyst, I want daily sales reports automated' (5 points)
- 'As a marketing team, I want customer segmentation data refreshed weekly' (8 points)
- 'As a business owner, I want a complete data lake architecture implemented' (too big - needs breaking down)

The same principles apply - focus on relative complexity and have collaborative discussions to reach consensus.
