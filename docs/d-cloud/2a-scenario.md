# Breakout Activity 2 – Cloud Architecture Scenarios

## Overview

You'll be given **a real-world data engineering scenario**.

Your task is to identify which **cloud services** are needed to build a solution - and **justify your choices**.

Focus on choosing the right combination of:

* **Storage**
* **Compute**
* **Integration**
* **Orchestration**

Use the products you identified in Activity 1 for your assigned cloud provider.

---

## Group Instructions

### Step 1: Read Your Scenario

Each group gets a different scenario. Read it carefully and discuss the key requirements.

### Step 2: Choose Cloud Services

As a group, decide which cloud services would meet the scenario's needs.

Record your selections in a table like this:

| Requirement                         | Cloud Service(s) | Why This Choice? |
| ----------------------------------- | ---------------- | ---------------- |
| Data storage                        |                  |                  |
| Ingesting data                      |                  |                  |
| Processing (batch/stream)           |                  |                  |
| API or integration                  |                  |                  |
| Workflow orchestration              |                  |                  |
| Other (e.g., analytics, dashboards) |                  |                  |

!!! tip "There’s no single correct answer"

    - The goal is to make informed design decisions and explain your thinking.

---

### Step 3: Present Back

Each group presents:

* The scenario summary (in your own words)
* The services you chose
* Key decisions or trade-offs you discussed

Keep it to **3 to 4 minutes per group**.
