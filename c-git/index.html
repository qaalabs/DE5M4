    Topic C ~ Git & GitHub¶

    1. Git Introduction¶

    Welcome and objectives¶

    • Explain the importance of source control in professional development environments
    • Connect to real-world applications in data engineering/analysis roles

    What is Git?¶

    • Explain Git as a distributed version control system
    • Distinguish between Git (tool) and GitHub (hosting service)
    • Highlight key benefits: tracking changes, collaboration, branching, history

    Core Git concepts¶

    • Repository, commit, branch, merge
    • Local vs. remote repositories
    • Basic workflow: clone, add, commit, push, pull

    2. Forking a Repository¶

    Demonstration¶

    • Show the process of forking a public repository
    • Explain the difference between forking and cloning
    • Demonstrate setting up upstream to keep fork updated
    • Show how to propose changes back to original repository

    Exercise 1: Forking a Repository¶

    • Fork a repository ~ https://github.com/ingwanelabs/intro-to-github
    • Clone their fork locally
    • Set up upstream connection
    • Make and commit a simple change
    • Update their fork from upstream

    3. Handling Merge Conflicts¶

    Demonstration¶

    • Explain what merge conflicts are and why they happen
    • Show how to identify conflicts in Git
    • Demonstrate resolving a simple merge conflict
    • Emphasize best practices to avoid unnecessary conflicts

    Exercise 2: Handling Merge Conflicts¶

    • Create a test repository
    • Create and modify files on different branches
    • Deliberately cause a merge conflict
    • Resolve the conflict
    • Complete the merge

    4. Revert and Reset¶

    Demonstration¶

    • Explain the difference between revert and reset
    • Show when to use each command
    • Demonstrate various reset options (soft, mixed, hard)
    • Highlight potential dangers with reset

    Exercise 3: Revert and Reset¶

    • Create a repository with multiple commits
    • Use revert to undo a commit
    • Use reset to move back to an earlier commit
    • Observe the differences between these commands

    5. GitHub Reviews¶

    Demonstration (Optional)¶

    • Explain GitHub's pull request review process
    • Show how to request reviews, add comments, approve/request changes
    • Demonstrate best practices for code reviews

    Exercise 4: GitHub Reviews¶

    Pair up learners to: - Create pull requests for each other to review - Practice commenting on code - Approve or request changes - Merge approved pull requests

    6. Workshop Review¶

    Key concepts recap¶

    • Review the main Git commands and workflows learned
    • Emphasize how these skills apply to data engineering/analysis work

    Q&A session¶

    • Address any remaining questions or confusion

    Next steps and resources¶

    • Suggest resources for further learning
    • Connect these skills to upcoming modules in their apprenticeship
    • Provide a simple "Git cheat sheet" with key commands ~ https://education.github.com/git-cheat-sheet-education.pdf
