    Topic B ~ Agile Product Planning¶

    Scenario: QARestaurant¶

    Below are a set of requirements for a restaurant's website.

    ✔ A logo needs to be designed for QARestaurant using a leaf-based theme to show it is a vegan restaurant.

    ✔ The Customer needs to view the logo in the navbar, the webpage tab and in the footer.

    ✔ The Customer needs to view social media links so that they can follow the restaurant on different platforms.

    ✔ The Customer needs to view and switch between the following webpages:

    • Our Menu: each item should have a title, description and price.
    • About Us: this should include an explanation of what veganism is, a few pictures of example vegan cuisine, and the head chefs.
    • Order Online: customers need to be able to order items online.
    • Reservations: customers need to be able to place table reservations on the website. Customers can only place a reservation 1 month in advance and need to be able to view tables which are available for reservation.
    • Contact Us: how to contact the restaurant

    ✔ Customer needs to visually see that the restaurant is located at: Anchorage 1 Anchorage Quay Salford, The Quays, Manchester M50 3YJ

    ✔ Restaurant Staff need to be able to both update and delete reservations if they receive a call.
