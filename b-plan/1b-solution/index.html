    Activity 1 - solution¶

    The Restaurant Website Scenario¶

    Learners were given requirements for a vegan restaurant website (QARestaurant) and tasked with creating appropriate epics, product backlog items, and tasks.

    Epic Examples¶

    Based on the restaurant requirements, these 5 main epics were identified:

    1. Restaurant Brand Identity¶

    • Covers all aspects of establishing the restaurant's visual identity
    • Includes logo design and consistent branding across the website

    2. Customer Website Navigation¶

    • Includes all features related to how customers move between different parts of the website
    • Navigation menus, responsive design, user experience

    3. Online Ordering System¶

    • Encompasses the entire online food ordering capability
    • Shopping cart, payment processing, order management

    4. Reservation Management System¶

    • Covers the full table reservation functionality for both customers and staff
    • Booking system, availability management, staff reservation tools

    5. Restaurant Information Display¶

    • Includes all informational content about the restaurant
    • Location, about us content, contact details, menu display

    Hierarchical Structure¶

    We then broke these epics down into:

    • Features (like "Data Ingestion Pipeline" under a larger epic)
    • User Stories (specific user needs within each feature)
    • Tasks (technical work items to complete user stories)

    Learning Objectives¶

    • Understand the hierarchy: Epic > Feature > User Story > Task
    • Practice identifying appropriate epic-level themes from business requirements
    • Learn to group related functionality under meaningful epic names
    • Connect epic planning to the broader Agile framework introduced in the morning

    This activity helped learners see how high-level business requirements get organized into manageable epic-level themes that can then be planned and developed iteratively.
